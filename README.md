
# 👋 Ali Kamali — Personal Portfolio

A modern, animated personal portfolio website showcasing my work and projects. I'm passionate about **electronics and computers**, and this site is where I share what I build and learn.

🔗 **Live Demo:** _[add your GitHub Pages link here]_

## ✨ Features

- 🎨 Sleek, modern UI with smooth **AOS scroll animations**
- 🌗 Light / Dark theme toggle
- ⌨️ Animated typing effect in the hero section (Typed.js)
- 🖱️ Interactive 3D tilt effect on project cards (Vanilla-Tilt)
- ✨ Particle background animation (Particles.js)
- 💻 Syntax-highlighted code snippets (Prism.js)
- 📱 Fully responsive design (Bootstrap 5)
- 📬 Contact section with direct email & social links

## 🛠️ Tech Stack

| Category | Tools |
|---|---|
| Markup / Styling | HTML5, CSS3, Bootstrap 5 |
| Scripting | Vanilla JavaScript |
